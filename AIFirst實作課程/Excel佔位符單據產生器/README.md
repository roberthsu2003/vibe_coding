## 🤖 第三步：專案生成提示詞（點擊代碼框右上角一鍵複製）

請將以下整段提示詞複製，貼到 **Google AI Studio**：

```markdown
# Role（角色）
你是一位精通 React、TypeScript、Tailwind CSS 與現代 UI/UX 設計的資深前端工程師，專精於純前端 Excel 自動化（ExcelJS）與模板引擎架構。

# Context（背景情境）
這是一個免伺服器、零 API Key 的「通用型 Excel 佔位符單據產生器（Universal Template Filler）」。
系統需預載專案 `public/商務報價單範本.xlsx` 檔案，自動掃描工作簿中所有 `{{變數名稱 | 預設值}}` 語法，在網頁上動態產生輸入欄位；使用者編輯後，一鍵將數值填回 Excel 儲存格，並保留原有範本的所有圖片（Logo）、頁首頁尾、樣式與公式，直接下載匯出！

# Task（任務目標）
請使用 `vite-react-typescript` 與 Tailwind CSS 建立單一頁面應用程式（SPA）：

1. **安裝相依套件**：使用 `exceljs` 與 `file-saver`（包含 `@types/file-saver`）。
2. **範本自動讀取與佔位符解析**：
   - 網頁初始化時，透過 `fetch('/商務報價單範本.xlsx')` 取得 ArrayBuffer，以 `workbook.xlsx.load(buffer)` 載入。
   - 使用正則表達式 `/\{\{\s*([^\|\}]+?)(?:\s*\|\s*([^\{\}]+?))?\s*\}\}/g` 遍歷所有儲存格文字。
   - 提取出：變數名稱（Key）、預設值（Default Value，若有 `|` 則取後方文字）、儲存格所在位置。
3. **動態表單與即時編輯介面**：
   - 依據解析出的變數自動生成表單欄位，並預先填入預設值。
   - 長文字（條款、備註）自動採用 Textarea，短文字採用 Input。
   - 支援搜尋欄位關鍵字、一鍵「重設回預設值」、一鍵「清空所有欄位」。
   - 頂部提供範本快速切換按鈕：
     - `[📄 載入商務報價單範本]`（讀取 `/商務報價單範本.xlsx`）
     - `[📑 載入商業請款單範本]`（讀取 `/商業請款單範本.xlsx`）
4. **支援上傳自訂範本（Custom Template Upload）**：
   - 提供拖曳或點擊上傳 `.xlsx` 區域。
   - 使用者上傳任何自訂 Excel 時，以 `FileReader` 讀取並動態重新掃描變數，立即產生新的對應輸入表單。
5. **一鍵填寫並匯出下載**：
   - 點擊「📥 匯出並下載 XLSX」按鈕。
   - 將使用者輸入的數值填回對應儲存格（替換 `{{...}}` 佔位符）。
   - **核心要求**：完整保留原範本內的 Logo 圖片、Header/Footer 設定、背景色、框線與計算公式（如 `=D*F`、`=SUM(...)`）。
   - 透過 `file-saver` 觸發下載（檔名：`填寫完成_[原範本名]_[日期].xlsx`）。

# Constraints（限制與規格要求）
1. 【純前端運算】：嚴禁依賴後端伺服器或外部 API Key。
2. 【現代商務美學】：
   - 配色以 Slate 深灰藍（`#1E293B`）與質感淺灰（`#F8FAFC`、`#E2E8F0`）為主，搭配藍色高亮（`#2563EB`）。
   - 卡片式排版、清晰分區、流暢微動畫與載入狀態（Loading Spinner）。
3. 【容錯防呆】：
   - 若 public 範本尚未放置，顯示友善提示引導使用者上傳自訂檔案，不可當機。
   - 上傳非 xlsx 檔案時給予提示。

# Format（交付格式）
1. 列出安裝指令（`npm i exceljs file-saver && npm i -D @types/file-saver`）。
2. 提供完整、無省略、具備完整型別定義的單一程式碼檔案（如 `src/App.tsx`）。
3. 簡短執行指引。
```

## 💡 自訂範本語法規則（只需 1 分鐘了解）

如果您想用 Excel 製作自己的專屬單據範本，只要在儲存格填入以下語法即可：

- **含預設值（最推薦）**：`{{變數名稱 | 預設值}}`  
  *例如：`客戶名稱：{{CLIENT_NAME | 宏達數位傳媒行銷有限公司}}`*
- **無預設值**：`{{變數名稱}}`  
  *例如：`發票號碼：{{INVOICE_NO}}`*
- **圖片與公式**：在 Excel 中正常插入圖片（如 Logo、印章）與設定公式（如 `=D13*F13`、`=SUM(...)`），系統匯出時會**完全保留**！
