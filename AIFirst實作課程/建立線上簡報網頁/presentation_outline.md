## 📌 Slide 2: 現狀挑戰與改善解方 (Problems & Solutions)
- **版型類型**: `split-columns`
- **分類標籤**: 現況診斷與策略
- **主標題**: 營運三大瓶頸 vs. NexFlow 核心改善策略
- **副標題**: 從傳統高耗時的人工作業，邁向端到端全自動化協作
- **左欄【現狀三大瓶頸痛點】**:
  1. **跨系統資料孤島**: 業務、財務與 ERP 系統資料互不相通，需大量人工手動匯出與比對 Excel。
  2. **重複性人工作業繁重**: 員工每日平均耗費 2.5 小時在日常單據登打與審核流轉，易疲勞且錯誤率高。
  3. **數據回報時效滯後**: 管理階層無法即時掌握最新營運狀況，往往需等待每週或每月匯總報表。
- **右欄【NexFlow 對應解方】**:
  - **全域 API 智慧串接**: 一鍵整合異質系統，資料零時差自動同步。
  - **無代碼工作流引擎**: 各部門業務人員即可直覺拉取自動化邏輯，釋放 40% 以上日常工時。
  - **實時監控儀表板**: 營運數據即時可視化，異常狀況主動警示派發。
> **講者備忘錄 (Speaker Notes)**: 請強調目前人工作業耗時嚴重，這不是個人效率問題，而是系統缺乏自動化串接。NexFlow 是以解救員工日常重複性工時為核心初衷。

## 📌 Slide 3: 核心架構與 4 階段業務工作流 (Architecture & Workflow)
- **版型類型**: `workflow` (三或四節點橫向流程)
- **分類標籤**: 系統運作架構
- **主標題**: 端到端全自動化 4 階段處理流程
- **副標題**: 毫秒級事件驅動架構，實現從觸發到通知的全鏈條自動化閉環
- **4 個流程階段內容 (未來升級為 SVG 動態路徑)**:
  1. **階段 01：多來源資料採集 (Data Ingestion)**
     - 整合 ERP、CRM、Email 與 LINE/Slack 傳入事件，自動擷取表單與附件資訊。
  2. **階段 02：AI 智能邏輯分析 (AI Logic Engine)**
     - 運用自然語言理解與規則引擎自動分類審查、檢驗合規性與萃取關鍵欄位。
  3. **階段 03：自動化任務派發 (Task Automation)**
     - 根據業務邏輯自動觸發審批流程、資料庫回寫及外部 API 連動派送。
  4. **階段 04：即時可視化回報 (Instant Dashboard & Alert)**
     - 即時更新看板儀表板，並透過即時通訊軟體主動向主管回報處理進度。
> **講者備忘錄 (Speaker Notes)**: 這裡是整個提案的技術核心。說明資料是如何從多個管道進入，經由 AI 邏輯辨識後，自動流轉並即時回饋，後續此頁會以生動的 SVG 向量動效展示。

- **副標題**: 數據化驗證專案價值，顯著提升產能並降低企業營運風險
- **4 大關鍵數據卡片 (未來升級為 Chart 動態圖表與切換表單)**:

## 📌 Slide 5: 核心產品亮點：NexFlow Edge 邊緣智慧運算核心 (Showcase)
- **版型類型**: `showcase`
- **分類標籤**: 旗艦核心技術
- **主標題**: NexFlow Edge 邊緣智慧運算核心展示
- **副標題**: 本地化輕量部署、軍規級端對端加密與極速響應能力
- **核心技術特色**:
  - **極速低延遲**: 本地硬體協同運算，最快 10ms 內完成複雜自動化決策。
  - **資料不落地安全架構**: 敏感商務個資與交易記錄均在企業內網加密運算，完全符合 ISO 27001 規範。

- **展示物描述 (未來升級為 3D 模型互動)**:
  - 立體科技硬體核心魔方，外層具備動態發光電路粒子，象徵高效運算的中樞心臟。
