# 雲端智慧庫存管理系統 📊

本單元將帶領大家完成一個非常實用的**雲端智慧庫存管理系統**！我們將結合 **Google Sheets（Google 試算表）** 作為雲端資料庫，並使用 **Google Apps Script (GAS)** 部署一個具備自動計算、ID 遞增與完整 **CRUD（新增、查詢、修改、刪除）** 功能的後端 API。

最後，我們會配合精心設計的單一網頁前端檔案 (`index.html`)，採用現代**毛玻璃美學 (Glassmorphism)** 與**暗黑/亮光主題切換**，讓您無需安裝任何軟體與環境，雙擊檔案即可在本地直接連線操作！

---

## 📅 課程架構與步驟流程

1. **第一階段：資料庫準備**（在雲端硬碟建立並匯入庫存資料）
2. **第二階段：部署雲端 API 後端**（複製 Apps Script 並發布為網頁應用程式）
3. **第三階段：執行極致美感前端**（本地雙擊打開網頁，貼上網址即刻啟動）

---

## 🛠️ 第一階段：資料庫準備

這部分需要正確設定 Google 試算表，請按步驟仔細操作：

### 步驟 1：建立並設定 Google 試算表 (Google Sheets)
1. 前往 [Google 雲端硬碟](https://drive.google.com/)，建議先**建立一個專屬資料夾**（例如：`AIFirst_庫存管理`）並進入。
2. 點擊左上角「**新增**」 > 「**Google 試算表**」，並將左上角的檔案名稱命名為「**庫存管理系統**」。
3. **匯入現有庫存資料**：
   - 點擊上方選單的 **「檔案」 > 「匯入」**。
   - 選擇「**上傳**」，將本資料夾下的 **`庫存.xlsx`** 拖曳上傳。
   - 在匯入位置選擇 **「取代目前工作表」**，點擊 **「匯入資料」**。
   - **⚠️ 檢查要點**：請確認左下角的工作表（分頁）名稱是否精確為 **`Inventory list`** (注意大小寫，結尾不要有空格)。
   - 此時，您會看到欄位包含 `需要再訂購`、`庫存 ID`、`名稱`、`單價` 等列。

---

## 💻 第二階段：部署雲端 API 後端 (Google Apps Script)

### 步驟 2：複製貼上後端程式碼 (GAS)
1. 在剛剛建立的「庫存管理系統」試算表上方選單中，點擊 **「擴充功能」 > 「Apps Script」**。
2. 開啟瀏覽器編輯器後，將預設的 `function myFunction() {}` 全部刪除。
3. 打開本資料夾底下的 **`gas_script.gs`** 檔案，將裡面的**所有程式碼複製**。
4. 將程式碼貼入 Google Apps Script 編輯器中。
5. 點擊編輯器上方工具列的「**儲存**」💾 圖示（或按快捷鍵 Ctrl+S / Cmd+S），並將專案名稱命名為「**InventoryAPI**」。

### 步驟 3：部署並取得 API 網址 (極度重要！)
這是讓前端網頁能夠透過網路讀寫 Google 試算表資料的關鍵步驟：
1. 點擊右上角的藍色按鈕 **「部署」 > 「新增部署作業」**。
2. 點擊「選取類型」旁邊的齒輪圖示 ⚙️，勾選 **「網頁應用程式」**。
3. 填入以下欄位設定：
   - **說明**：`V1.0.0`
   - **執行身分**：選擇 **「我」** (您的 Google 帳號)。
   - **誰可以存取**：**務必選擇「所有人」** (這樣前端才能跨網域讀寫 API)。
4. 點擊 **「部署」** 按鈕。
5. **授權存取**（初次部署會要求帳號權限）：
   - 點擊「**授權存取**」，選擇您的 Google 帳號。
   - 若出現安全警告「Google 尚未驗證此應用程式」，請點擊左下角的「**進階**」 > 「**前往 InventoryAPI（不安全）**」。
   - 點擊「**允許**」。
6. 部署成功後，會看到 **「網頁應用程式網址」 (Web App URL)**。
7. **📋 請將這串網址完整複製並妥善保存**，我們在第三階段馬上會用到！

> [!WARNING]
> **⚠️ 未來修改 GAS 程式碼的大魔王注意事項：**
> 如果您未來修改了 Google Apps Script 中的任何程式碼，**僅僅點擊「儲存」是絕對不會在線上生效的！** 
> 
> 您必須完成以下步驟，否則線上跑的永遠是舊程式碼：
> 1. 點擊右上角「部署」 > 「**管理部署作業**」。
> 2. 點擊右上角的 **「編輯」** (鉛筆圖示 ✏️)。
> 3. **關鍵步驟**：在「版本」下拉選單中，**一定要選擇「建立新版本」**！
> 4. 點擊右下角的 **「部署」**。

## 🎨 第三階段：執行極致美感前端 (本地雙擊運行)

我們的 `index.html` 網頁前端使用了現代**毛玻璃美學 (Glassmorphism)** 設計，並內建了 API 設定小面板，您不需要編輯任何程式碼即可直接使用！

### 步驟 4：打開網頁並設定 API 網址
1. 在本資料夾中找到 **`index.html`**，用您的瀏覽器 **「雙擊打開它」**。
2. 首次開啟時，網頁會自動跳出 **「Google Apps Script API 設定」** 對話框。
3. 將您在 **第二階段步驟 3** 複製的 **「網頁應用程式網址」** 貼入輸入框中。
4. 點擊 **「儲存並連接」**。
5. 網頁會立刻與您的 Google 試算表進行連線同步，並載入您 Excel 的商品清單！🎉

## ✨ 系統亮點功能介紹

- 💡 **四大核心數據指標卡 (KPI)**：
  - **總庫存品項數**：即時統計庫存總商品種類。
  - **庫存資產總價值**：以 `單價 * 數量` 計算，即時展示總庫存資產額。
  - **安全庫存補貨警示**：若商品數量低於設定的「再訂貨點」，會自動將其標記為「需補貨 ⚠️」並計入警示卡中。
  - **停產商品項目**：統計目前已經停產的品項數量。

- 🎨 **暗黑 / 亮光主題切換**：
  - 點擊頂部右上角的「太陽/月亮」圖標，可在精心調配的**迷霧藍暗黑模式**與**簡約亮白模式**之間平滑切換。

- ⚡ **雙向即時運算表單**：
  - 在新增或編輯商品時，只要輸入「單價」與「庫存數量」，表單下方的微型小工具會**即時顯示估算總價值**。
  - 當您輸入的「數量」低於「再訂貨點」時，表單會即時彈出**黃色警告**，提醒您注意庫存不足！

- 🔍 **高效搜尋與多重篩選**：
  - **即時搜尋**：輸入關鍵字，可即時過濾 ID、商品名稱或規格描述。
  - **快速篩選標籤**：可一鍵切換查看「全部品項」、「充足 ✅」、「需補貨 ⚠️」或「已停產 🚫」商品。
  - **表頭排序**：點擊表格標題（例如單價、數量、總價值），能對庫存清單進行正序或倒序排列。

- 🛑 **自訂模態視窗與 Toast 提示**：
  - 捨棄了瀏覽器難看的預設彈出視窗，全面採用毛玻璃磨砂效果的「二次刪除確認框」與右上角「自動淡出 Toast 訊息通知」，為使用者帶來極致的 UX 體驗。
