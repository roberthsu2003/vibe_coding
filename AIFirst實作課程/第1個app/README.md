## 🚀 AI First 雙工具實戰流程：Gemini 分析 ➔ AI Studio 生成

在純前端網頁開發中，`public/` 資料夾主要用於存放靜態圖檔或全域資產，放二進位試算表檔案並在前端以 fetch 讀取常受到路徑、打包與權限限制；同時 Google AI Studio 介面本身也無法直接上傳 `.xlsx` 檔案進行分析。

因此，最標準且優雅的 **AI First 解決方案** 是雙 AI 工具分工協作：

```
[ 步驟 1：Google Gemini ]  ───────────────►  [ 步驟 2：Google AI Studio ]
上傳《商務報價單範本.xlsx》                   貼上 RTCCF 提示詞
  + 輸入自然語言指令                            + 生成 React + TypeScript 程式碼
  ➔ 自動解析結構與配色產生 RTCCF Prompt          ➔ 使用 exceljs 純前端完整渲染下載
```

1. **第一站：Google Gemini（多模態文件分析）**：
   - 前往 [Google Gemini](https://gemini.google.com)，Gemini 支援直接上傳 `.xlsx` 試算表檔案！
   - 將本專案的 [`商務報價單範本.xlsx`](./商務報價單範本.xlsx) 檔案上傳給 Gemini。
   - 要求 Gemini 深入解析儲存格結構、合併範圍、公式與精確 Hex 色票，並使用 **RTCCF 框架** 產出指定使用 **`exceljs`** 套件的程式開發提示詞。
2. **第二站：Google AI Studio（代碼生成與即時預覽）**：
   - 將 Gemini 產出的 RTCCF 提示詞貼入 Google AI Studio。
   - 透過 `exceljs` 在前端直接以程式碼渲染出 100% 相同排版與配色的 Excel，零後端依賴、零靜態檔限制！

### 🔄 Google AI Studio 迭代修改技巧
在建立與微調專案時，建議善用以下三種迭代方式：
1. **Prompt Chat**：直接透過對話框提出全局修改（如：「請幫我新增匯出 XLSX 功能」）。
2. **Focus Mode（聚焦模式）**：圈選特定程式碼或畫面區塊，針對該局部進行邏輯或文字修改。
3. **Annotate Mode（標註模式）**：在預覽畫面上直接做視覺化標註與回饋，調整排版與顏色。

## 🤖 專案生成提示詞（RTCCF 格式）

請將以下提示詞複製並貼至 **Google AI Studio** 中進行生成：

```markdown
# Role（角色）
你是一位精通 React、TypeScript 與現代化 UI/UX 設計的資深前端工程師，同時也是專精於純前端辦公室自動化（Office Automation）與試算表樣式設計的專家。

# Context（背景情境）
這是一個專為辦公室業務、專案經理與行政人員設計的「商務報價單產生器（Quotation Generator）」。
使用者希望在不需要任何後端伺服器與 API Key 的情況下，透過純前端網頁直覺地填寫/微調報價資料，並能一鍵下載排版精美、具備企業級質感的 Excel (.xlsx) 檔案。

# Task（任務目標）
請使用 `vite-react-typescript` 與現代 CSS（或 Tailwind CSS）建立一個單一頁面應用程式（SPA）：
1. 預載完整的 Placeholder 範例資料（公司名稱、Logo 圖示預留位置、客戶資訊、報價項目清單、條款與備註）。
2. 提供即時響應式預覽與編輯介面（支援即時增刪品項、數量與單價變動即時重算未稅額、5% 營業稅與總金額）。
3. 實作「下載精美 Excel (.xlsx)」按鈕（核心重點）：
   - 點擊後利用純前端套件 **`exceljs`** 與 `file-saver`，完全在瀏覽器端以程式碼動態建構並下載企業級 .xlsx 檔案。
   - 必須嚴格遵照標準商務規範渲染儲存格背景色、字型、公式與邊框，絕不隨意使用非標準顏色。

# Constraints（限制與規格要求）
1. 【零後端與零 API Key】：
   - 全功能純前端運算，嚴禁依賴任何後端伺服器或外部 API Key。
2. 【網頁 UI 設計規範】：
   - 外觀必須極具現代商業感（深淺層次、簡潔卡片、清爽字體、精緻按鈕）。
   - 頂部包含 Logo 預覽（可使用 SVG 幾何圖形或 Canvas 產生預設企業 Logo）、標題、報價單號與有效期限。
   - 提供「重設為範本」、「新增項目」與「一鍵下載 XLSX」等清晰按鈕。
3. 【Excel (.xlsx) 嚴格欄位與排版規範（關鍵：使用 exceljs 程式碼渲染）】：
   - **Title & Logo 區（A2:G4）**：
     - `A2:B4` 合併作為 Logo 佔位區（背景色 `#F1F5F9`、文字 `#1E293B`，加細框線）。
     - `C2:G2` 合併為大標題 "商 務 報 價 單 / QUOTATION"（18pt、文字顏色 `#0F172A`）。
     - `C3:G3` 為單號、日期與有效天數（文字顏色 `#64748B`）。
     - `C4:G4` 為專案名稱（文字顏色 `#334155`）。
   - **基本資訊區（A6:G10）**：
     - 雙欄排版：`A6:C6`（【 供應商資訊 (我方) 】）與 `E6:G6`（【 客戶買受人資訊 】）為標題列，**背景色 `#E2E8F0`**、文字色 `#1E293B`。
     - 內容列（Row 7~10）：公司名稱、統編、電話、地址，文字顏色 `#334155`，無底色。
   - **明細表格區（Row 12 起）**：
     - **表頭（Row 12）**：**背景色 `#1E293B`（深灰藍）**、文字純白粗體 `#FFFFFF`、高 24px。
     - 欄位 A（寬 8）：項次（置中）
     - 欄位 B（寬 22）：項目名稱（靠左）
     - 欄位 C（寬 30）：規格說明與功能簡述（靠左）
     - 欄位 D（寬 10）：數量（置中，格式 `#,##0`）
     - 欄位 E（寬 8）：單位（置中）
     - 欄位 F（寬 15）：單價 NTD（靠右，格式 `NT$ #,##0`）
     - 欄位 G（寬 16）：小計金額 NTD（靠右，公式 `=D{row}*F{row}`，格式 `NT$ #,##0`）
     - **斑馬紋交替底色**：奇數列 `#FFFFFF`、偶數列 `#F8FAFC`，所有資料列均需加上細框線。
   - **金額加總區**：
     - 銷售額合計（未稅）：白底，公式 `=SUM(G13:G{lastRow})`
     - 加值型營業稅（5%）：白底，公式 `=ROUND({未稅儲存格}*0.05, 0)`
     - 總計金額（含稅 NTD）：**背景色 `#E2E8F0`**，文字標籤 `#0F172A`，數值顏色 `#1E3A8A`（12pt 粗體加雙底線）。
   - **Footer 頁尾條款與簽核區**：
     - 包含 3 點付款條款與匯款帳號（字色 `#64748B`）。
     - 底部雙欄「供應商簽章用印欄」與「客戶確認回傳欄」：Row 27 標題列底色 `#F8FAFC`，下方留白 3 列作為蓋印簽名區。
4. 【嚴格配色色彩規範（嚴禁隨便設定背景色）】：
   - 全面遵循上述 Slate 商業色票（`#1E293B`、`#E2E8F0`、`#F1F5F9`、`#F8FAFC`），禁止使用其他未定義顏色。
5. 【資料流與容錯】：
   - 確保所有金額輸入為動態即時計算。
   - Excel 匯出過程必須有 Loading 狀態與防呆機制，檔名預設為 `報價單_[單號]_[日期].xlsx`。

# Format（交付格式）
1. 列出所需安裝的相依套件指令（包含 `exceljs`、`file-saver` 及其 `@types`）。
2. 提供完整、無省略、具備完整 TypeScript 型別定義的單一程式碼檔案（例如 `App.tsx`）或關鍵模組。
3. 提供簡短的執行與測試步驟說明。
```
