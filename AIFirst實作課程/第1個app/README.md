> **核心特色**：
> - 🚫 **零 API Key 門檻**：純前端運算，不需要申請或暴露任何 API 金鑰。

> - 📊 **精美 Excel (.xlsx) 下載**：包含企業 Logo、商務配色表頭、千分位金額與頁尾簽核欄。
> - 📁 **官方範本檔案**：[📥 下載標準範本：商務報價單範本.xlsx](./商務報價單範本.xlsx)（可用 Excel 或 Google 試算表開啟對照格式；若在 AI Studio 開發可放至專案的 `public/` 資料夾）。

## 📋 標準輸出 Excel 欄位與結構規範
為了確保程式匯出的 Excel 與標準範本完全一致，結構分為以下五大區塊：

| 區塊 | 儲存格位置 | 內容與格式說明 |
| :--- | :--- | :--- |
| **1. Logo 與大標題** | `A2:B4`（合併）<br>`C2:G2`（合併）<br>`C3:G3`（合併） | - **Logo 佔位**：`❖ ACME CORP 智慧科技`，淺灰底加框置中。<br>- **大標題**：`商 務 報 價 單 / QUOTATION`（18pt 粗體深藍）。<br>- **單據中繼資料**：單號（QT-）、報價日期、有效天數（30天）。 |
| **2. 雙欄基本資訊** | `A6:C10`（我方）<br>`E6:G10`（買受人） | - 公司名稱、統一編號、聯絡窗口/電話、通訊地址。<br>- 標題列套用淺灰背景填色（`#E2E8F0`）。 |
| **3. 明細清單表格** | `Row 12`（表頭）<br>`Row 13~17`（資料） | - **A欄（寬8）**：項次（No.，置中）<br>- **B欄（寬22）**：項目名稱（靠左）<br>- **C欄（寬30）**：規格說明與功能簡述（靠左）<br>- **D欄（寬10）**：數量（Qty，置中）<br>- **E欄（寬8）**：單位（Unit，置中）<br>- **F欄（寬15）**：單價（Unit Price，靠右，格式 `NT$ #,##0`）<br>- **G欄（寬16）**：小計金額（Amount，公式 `=D*F`，格式 `NT$ #,##0`）<br>- 表頭為深藍色背景（`#1E293B`）與白字粗體，交替列淺色底紋。 |
| **4. 金額匯總加總** | `Row 18~20` | - **Row 18**：銷售額合計 (未稅 Subtotal) → 公式 `=SUM(G13:G17)`<br>- **Row 19**：加值型營業稅 (VAT 5%) → 公式 `=ROUND(G18*0.05, 0)`<br>- **Row 20**：總計金額 (含稅 Grand Total) → 公式 `=G18+G19`，粗體加雙底線。 |
| **5. 條款與簽章區** | `Row 22~25`（條款）<br>`Row 27~30`（簽核） | - 付款條件（訂金 30%、期中 40%、結案 30%）、匯款銀行帳號。<br>- 雙欄簽名欄：我方發票章蓋印處 / 客戶簽章確認回傳處。 |

## 🛠️ Google AI Studio 實作與迭代技巧

### 📌 實務工作流程：如何整合 Excel 範本？
> **痛點**：Google AI Studio 的介面目前無法直接上傳 `.xlsx` 二進位試算表檔案。  
> **實務解法**：
> 1. **第一步（先請 AI 建立專案）**：先複製下方的提示詞交給 AI Studio，讓 AI 建立完整的 Vite + React 專案骨架與程式碼。
> 2. **第二步（建立 `public` 資料夾並手動置入範本）**：在專案根目錄確認或建立 `public/` 資料夾，並手動將課程提供的 [`商務報價單範本.xlsx`](./商務報價單範本.xlsx) 複製放至 `public/` 目錄中。
> 3. **第三步（對照與取用）**：
>    - 網頁端可直接透過 `/商務報價單範本.xlsx` 靜態路徑提供「下載官方標準範本」功能。
>    - 開發者與學員亦可直接將下載後的檔案與匯出成果進行即時視覺對照。

### 🔄 迭代修改技巧
在 Google AI Studio 建立與微調專案時，建議善用以下三種迭代方式：
1. **Prompt Chat**：直接透過對話框提出全局修改（如：「請幫我新增匯出 XLSX 功能」）。
2. **Focus Mode（聚焦模式）**：圈選特定程式碼或畫面區塊，針對該局部進行邏輯或文字修改。
3. **Annotate Mode（標註模式）**：在預覽畫面上直接做視覺化標註與回饋，調整排版與顏色。

## 🤖 專案生成提示詞（RTCCF 格式）

請將以下提示詞複製並貼至 **Google AI Studio** 中進行生成：

```markdown
# Role（角色）
你是一位精通 React、TypeScript 與現代化 UI/UX 設計的資深前端工程師，同時也是專精於純前端辦公室自動化（Office Automation）與試算表樣式設計的專家。

# Context（背景情境）
這是一個專為辦公室業務、專案經理與行政人員設計的「商務報價單產生器（Quotation Generator）」。
使用者希望在不需要任何後端伺服器與 API Key 的情況下，透過純前端網頁直覺地填寫/微調報價資料，並能一鍵下載排版精美、具備企業級質感的 Excel (.xlsx) 檔案。
**特別注意：專案的 `public/` 資料夾下已經預先放置好標準官方範本 `商務報價單範本.xlsx`**（前端可直接經由靜態路徑 `/商務報價單範本.xlsx` 存取）。

# Task（任務目標）
請使用 `vite-react-typescript` 與現代 CSS（或 Tailwind CSS）建立一個單一頁面應用程式（SPA）：
1. 預載完整的 Placeholder 範例資料（公司名稱、Logo 圖示預留位置、客戶資訊、報價項目清單、條款與備註）。
2. 提供即時響應式預覽與編輯介面（支援即時增刪品項、數量與單價變動即時重算未稅額、5% 營業稅與總金額）。
3. 實作「下載官方空白範本」功能：在介面上提供按鈕，點擊後直接下載靜態資源 `/商務報價單範本.xlsx`。
4. 實作「匯出報價單 Excel (.xlsx)」按鈕（核心重點）：
   - 點擊後透過純前端 `fetch('/商務報價單範本.xlsx')` 讀取範本的 ArrayBuffer。
   - 使用 `exceljs` 的 `workbook.xlsx.load(buffer)` 載入該範本，完美保留原本範本的 Logo 佔位、企業配色表頭、細框線與簽核欄樣式。
   - 將網頁上動態編輯的報價單號、客戶買受人資訊、明細品項與合計金額，精準填入對應的儲存格。
   - 透過 `file-saver` 觸發下載填寫後的 .xlsx 檔案。

# Constraints（限制與規格要求）
1. 【零後端與零 API Key】：
   - 全功能純前端運算，嚴禁依賴任何後端伺服器或外部 API Key。
2. 【網頁 UI 設計規範】：
   - 外觀必須極具現代商業感（深淺層次、簡潔卡片、清爽字體、精緻按鈕）。
   - 頂部包含 Logo 預覽（可使用 SVG 幾何圖形或 Canvas 產生預設企業 Logo）、標題、報價單號與有效期限。
   - 提供「重設為範本」、「新增項目」、「下載空白範本」與「匯出報價單 XLSX」等清晰按鈕。
3. 【Excel 範本載入與儲存格填充規範（關鍵）】：
   - 必須透過 `fetch('/商務報價單範本.xlsx')` 載入 public 範本，**嚴格依照以下位置寫入資料**：
     - **Title 資訊區**：
       - `C3`：寫入報價單號、報價日期與有效天數。
       - `C4`：寫入專案名稱。
     - **基本資訊區（客戶買受人）**：
       - `E7`：客戶名稱
       - `E8`：統一編號
       - `E9`：聯絡人 / 聯絡電話
       - `E10`：通訊地址
     - **明細表格區（Row 13 起填寫）**：
       - 欄 A（項次）：`1, 2, 3...`
       - 欄 B（項目名稱）：商品/服務品名
       - 欄 C（規格說明）：詳細規格簡述
       - 欄 D（數量）：數字數值
       - 欄 E（單位）：式 / 套 / 式等單位文字
       - 欄 F（單價 NTD）：數字單價
       - 欄 G（小計金額）：設定公式 `=D{row}*F{row}`
     - **金額加總區**：
       - 銷售額合計（未稅）：公式 `=SUM(G13:G{lastRow})`
       - 加值型營業稅（5%）：公式 `=ROUND({未稅儲存格}*0.05, 0)`
       - 總計金額（含稅 NTD）：公式 `={未稅儲存格}+{營業稅儲存格}`
4. 【資料流與容錯】：
   - 確保所有金額輸入為動態即時計算。
   - Excel 匯出過程必須有 Loading 狀態與防呆機制；若 fetch 範本失敗，應跳出友善提示通知使用者確認 `public/商務報價單範本.xlsx` 是否存在。
   - 下載檔名預設為 `報價單_[單號]_[日期].xlsx`。

# Format（交付格式）
1. 列出所需安裝的相依套件指令（包含 `exceljs`、`file-saver` 及其 `@types`）。
2. 提供完整、無省略、具備完整 TypeScript 型別定義的單一程式碼檔案（例如 `App.tsx`）或關鍵模組。
3. 提供簡短的執行與測試步驟說明。
```

## 💡 迭代練習指引（給學員）

當 Google AI Studio 生成出第一版後，可以嘗試練習以下微調：

1. **使用 Annotate Mode 調整配色**：
   - 標註表頭顏色，要求 AI：「將主色系換成沉穩的科技深藍（#0F172A），文字維持純白」。
2. **使用 Focus Mode 增加欄位**：
   - 選取明細項目，要求 AI：「在每個項目中多加一個『備註/規格說明』欄位，並同步更新至匯出的 Excel 欄位中」。
3. **功能擴充（純前端）**：
   - 請 AI 加上「儲存為草稿（LocalStorage）」功能，讓使用者下次打開網頁還能保留上次輸入的報價資料。
