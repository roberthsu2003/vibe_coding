# Prompt 內容格式：從自然語言到 Markdown 結構化

在請 AI 幫忙做事時，你「**怎麼說**」和「**說什麼**」一樣重要。同樣一個需求，用不同的文字格式寫給 AI，產出的結果可能天差地遠。

許多初學者習慣用「自然語言」隨性輸入，但在面對稍微複雜的職場任務時，往往會發現 AI 容易漏掉細節或產生偏誤。這時候，學會使用 **Markdown 結構化格式**，就是讓 AI 輸出從「及格」躍升到「精準專業」的關鍵分水嶺。

為了讓大家感受差異，我們用同一個職場情境來示範兩種格式的差異：

> **情境背景**：你是**華梵大學業務部**行政助理，明天下午兩點有「**季度業績檢討會議**」，地點在三樓會議室，要請業務部和行銷部全體同仁參加，需攜帶季度報告。  
> **目標**：請 AI 幫忙寫一封正式的會議通知信。

---

## 1. 自然語言（Natural Language）

✏️ **概念說明**

就像平時傳 LINE 給同事或隨口交辦事項一樣，想到什麼就打什麼，沒有固定的排版或結構規則。這是最直覺、最常見的 Prompt 寫法。

- **優點**：完全零門檻，不需要思考排版，打字即可發送。
- **缺點**：需求一多時容易變成「流水帳」，資訊扁平無層次，AI 容易忽略重要限制（例如忘記註記攜帶資料、漏掉地點或語氣不夠正式）。
- **適用場景**：簡單的一次性問答、隨想草稿、概念諮詢或聊天對話。

💡 **會議通知信範例**：

> 「請幫我寫一封會議通知信，是明天下午兩點的季度業績檢討會議，在三樓會議室，要請業務部和行銷部的同事參加，記得叫他們帶上季度報告。語氣正式一點。」

---

## 2. Markdown 結構化格式（Markdown Format）

✏️ **概念說明**

Markdown 是目前與大型語言模型（LLM）溝通**最推薦、最主流的結構化格式**。透過簡單的標記符號（`#` 標題、`-` 條列、`**` 粗體），就能將龐雜的資訊拆解成邏輯分明、層級清晰的模組區塊。

- **優點**：
  - **人機皆好讀**：人類閱讀一目了然，AI 解析時也能明確辨識各段落的權重與角色。
  - **降低遺漏率**：把「角色」、「任務」、「條件限制」與「輸出格式」明確分區，AI 不會漏看細節。
  - **易於重複使用**：結構化模組可以直接當成樣板，換個主題就能再次套用。
- **缺點**：需要熟悉幾個最基礎的 Markdown 符號（但只需花兩分鐘即可掌握）。
- **適用場景**：職場公文、信件撰寫、多步驟任務、會議記錄摘要、長篇報告生成等所有複雜工作。

💡 **會議通知信範例**：

```markdown
# 角色
你是一位經驗豐富的行政秘書，擅長撰寫正式、得體的商務信件。

## 任務
請幫我撰寫一封正式的會議通知信，發送給業務部與行銷部的全體同仁。

### 會議資訊
- **會議主題**：季度業績檢討會議
- **會議時間**：明天（請留日期變數欄位）下午 14:00
- **會議地點**：三樓會議室
- **出席人員**：業務部全體同仁、行銷部全體同仁

### 注意事項
- 請與會人員務必**攜帶本季度業績報告**。
- 若因故無法出席，請提前向部門主管請假。

## 輸出格式
- **信件語氣**：專業、禮貌、簡潔明確
- **信件結構**：
  1. 信件主旨（清楚標註會議名稱與日期）
  2. 正文通知與會議目的
  3. 會議時間、地點與出席人員條列清單
  4. 注意事項與備註
  5. 署名與聯絡方式
- **附加要求**：於信件末尾附上一行英文版主旨與簡要備註，方便轉發給外籍同仁。
```

## 兩者比較表

| 比較維度 | 自然語言（口語化） | Markdown 結構化 |
| :--- | :--- | :--- |
| **輸入方式** | 一段式純文字，想到什麼寫什麼 | 分層標題、條列清單、重點標註 |
| **資訊層次** | 扁平無層級，資訊容易混雜 | 樹狀結構，模組區塊清晰 |
| **AI 理解精確度** | 中等，指令複雜時容易漏項 | 極高，AI 能精準抓取各區塊限制 |
| **修改與維護** | 牽一髮動全身，不容易針對單點修改 | 模組化，可隨時替換特定條件或輸出要求 |
| **推薦使用時機** | 快速隨想、簡單查詢、探索式對話 | 正式工作產出、多條件任務、標準作業流程（SOP） |

## 實戰技巧：Markdown 在 Prompt 中的四大武器

撰寫結構化 Prompt 時，善用以下四種 Markdown 元素，就能讓 AI 瞬間抓到重點：

1. **標題分層（`#`、`##`、`###`）**  
   用來區分不同的指令區塊（如：`# 角色`、`## 任務`、`## 背景資訊`、`## 限制條件`、`## 輸出格式`）。
2. **無序/有序清單（`-`、`1.`）**  
   條列具體的要求、會議事項或執行步驟，避免長篇大論擠成一團。
3. **粗體強調（`**重點**`）**  
   強調關鍵字或絕對不能違反的規定（例如：**嚴禁使用簡體中文**、**字數上限 300 字**）。
4. **引用或代碼區塊（`>`、` ``` `）**  
   用來隔離「參考資料」、「範例文字」或「原始資料」，讓 AI 清楚知道哪些是你的指令、哪些是待處理的素材。

> 💡 **提示詞黃金架構（RTCCF）**：  
> 寫 Prompt 時，只要掌握以下五大要素，就能寫出專業級指令：  
> - **R（Role，角色）**：AI 的人設與專業背景  
> - **T（Task，任務）**：具體要做什麼事  
> - **C（Context，背景）**：事情的來龍去脈與相關資訊  
> - **C（Constraint，限制）**：規則、字數、語氣、不能做什麼  
> - **F（Format，格式）**：產出架構、表格或排版要求

## 🚀 課堂練習：換你來試試看！

請從以下 **5 個職場情境** 中挑選 **1 個** 你最有感的題目，練習將口語需求轉換成 **Markdown 結構化格式** 的 Prompt，並丟給 AI 測試產出效果！

🎯 **練習情境 5 選 1**：

### 1. 請 AI 幫你起草一封婉拒廠商的信
- **主題背景**：你是**華梵大學採購處**承辦人，收到「**OO 科技有限公司**」的設備報價，因本次預算有限無法合作，希望保留未來合作可能性。
- **思考方向**：說明拒絕原因、維持良好合作關係、語氣要禮貌但明確。

<details>
<summary>💡 點擊展開參考 Prompt 範本</summary>

<br>

```markdown
# 角色
你是一位有經驗的採購行政人員，擅長以得體、專業的方式處理廠商商務往來信件。

## 任務
請幫我撰寫一封正式的信件，婉拒廠商本次的設備報價。

### 背景說明
- 廠商名稱：OO 科技有限公司
- 拒絕原因：本次專案預算有限，暫時無法採購合作
- 期望目標：感謝廠商提案，並表達未來有新專案時仍期待合作的誠意

## 輸出格式
- **信件語氣**：禮貌、專業、堅定但不失溫度
- **信件結構**：
  1. 感謝對方來信與詳盡報價
  2. 說明本次無法合作的原因（預算考量）
  3. 保留未來合作彈性與感謝之意
  4. 正式商務署名
```

</details>

### 2. 請 AI 幫你整理一份會議記錄摘要
- **主題背景**：你是**吉他社**社團幹部，剛開完「**3 月社團會議**」，手上有雜亂的會議筆記，需要整理成正式紀錄給指導老師與社員。
- **思考方向**：把雜亂的會議筆記拆解為「基本資訊」、「決議事項」和「待辦追蹤（含負責人與截止日）」。

<details>
<summary>💡 點擊展開參考 Prompt 範本</summary>

<br>

```markdown
# 角色
你是一位細心且擅長邏輯歸納的行政秘書。

## 任務
請將以下雜亂的會議筆記，整理成結構清晰、重點突出的會議記錄摘要。

### 原始筆記內容
> （在此處貼上未經整理的會議筆記）

## 輸出格式
- **語氣風格**：客觀、中性、條理分明
- **排版結構**：
  1. **會議基本資訊**（時間、地點、出席名單）
  2. **核心討論議題**（重點概述）
  3. **決議事項**（用條列式清楚呈現）
  4. **後續待辦事項（Action Items）**：以 Markdown 表格呈現，欄位包含「待辦工作」、「負責人」、「預計完成日」
```

</details>

### 3. 請 AI 幫你寫一份新人到職的注意事項清單
- **主題背景**：你是**華梵大學資訊處**資深員工，下週有新同仁報到，需要製作一份「**資訊處新人到職注意事項**」，涵蓋報到流程、系統帳號申請、部門日常 SOP。
- **思考方向**：以新人的視角出發，步驟化說明第一週需要完成的事項。

<details>
<summary>💡 點擊展開參考 Prompt 範本</summary>

<br>

```markdown
# 角色
你是一位親切、熟悉校園與部門行政流程的資深 IT 同仁，負責協助新進同仁順利入職。

## 任務
請幫我撰寫一份「資訊處新進同仁到職第一週指引與注意事項清單」。

### 涵蓋重點
- 第一天報到應備文件與流程
- 必備系統帳號開通（學校 Email、公文差勤系統、內部伺服器權限）
- 部門日常基本規範（上下班簽到、資安規範、午餐與休息區域）

## 輸出格式
- **語氣風格**：友善、清晰，幫助新人消除入職緊張感
- **結構安排**：
  - 前言（歡迎詞）
  - 階段一：報到當日（Checklist）
  - 階段二：帳號與權限申請步驟
  - 階段三：常見問題（FAQ）與部門聯絡窗口
```

</details>

### 4. 請 AI 幫你製作一份出差費用申報說明
- **主題背景**：你是**華梵大學財務處**行政人員，需要製作「**出差費用申報說明**」供全校教職員參考，含交通、住宿、餐費上限與應檢附單據種類。
- **思考方向**：條列明確規範與費用上限，避免同仁送件被退件。

<details>
<summary>💡 點擊展開參考 Prompt 範本</summary>

<br>

```markdown
# 角色
你是一位熟稔學校法規的財務處行政人員，負責制定與宣導差旅費報銷規則。

## 任務
請幫我撰寫一份簡明扼要的「教職員出差費用申報指南與注意事項」。

### 規定要點
- 可申報項目：大眾交通運輸費（實報實銷）、國內住宿費、出差膳雜費
- 單據規範：統一發票需有抬頭與統一編號、高鐵與台鐵購票證明
- 申請期限：出差結束後 14 個工作天內需送件完畢

## 輸出格式
- **語氣風格**：正式、權威且指引明確
- **結構安排**：
  - 申報流程簡述
  - 各項目報支標準與單據要求（使用 Markdown 表格呈現）
  - 常見退件原因提醒
  - 財務處諮詢窗口
```

</details>

### 5. 請 AI 幫你寫一則內部停機維護公告
- **主題背景**：你是**華梵大學資訊處**行政人員，本週六晚上 10:00 至週日早上 6:00 進行「**全校內部 ERP 與差勤系統停機維護**」，需發布公告通知全體教職員。
- **思考方向**：清楚標示影響時間、受影響系統、注意事項與緊急聯絡窗口。

<details>
<summary>💡 點擊展開參考 Prompt 範本</summary>

<br>

```markdown
# 角色
你是學校資訊處的系統維運負責人，負責向全校發布系統維護停機公告。

## 任務
請撰寫一則全校性的內部系統停機維護公告信。

### 公告核心資訊
- 維護系統：校務內部 ERP 系統、差勤打卡系統
- 維護時段：本週六（日期）22:00 ～ 週日（日期）06:00
- 影響範圍：維護期間上述系統全面暫停服務，無法進行登入與審批作業
- 建議因應措施：請同仁提前完成請假或表單送審作業

## 輸出格式
- **語氣風格**：簡要、醒目、正式
- **結構安排**：
  - 公告主旨（需包含【系統維護通知】與日期關鍵字）
  - 重要資訊摘要（時間、影響項目使用粗體標註）
  - 詳細說明與因應建議
  - 緊急支援與諮詢聯絡窗口
```

</details>
